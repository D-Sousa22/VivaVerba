# VivaVerba
Trabalho de conclusão de curso, produzido por alunos do curso de informática para internet da Etec de Praia Grande.

# Objetivo
O objetivo do nosso projeto é ajudar, por meio da tecnologia, com a alfabetização de crianças de 5 a 10 anos. Com jogos educativos e divertidos, os separando por duas faixa-etárias diferentes.
